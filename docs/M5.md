# M5 — Hourly public transport data

Written by **Morks/Codex**. Reviewer and approver: **Yalçın**.

## Purpose and source

Add hourly rail observations so later stages can answer questions such as the
quietest hour. Source: IBB Open Data's
[hourly public transport dataset](https://data.ibb.gov.tr/dataset/hourly-public-transport-data-set),
discovered with `package_show?id=hourly-public-transport-data-set`.
Data is licensed under the [İBB Açık Veri Lisansı 1.0](https://data.ibb.gov.tr/license);
the attribution in the README applies.

## Stages

1. **Ingest (this stage):** stream monthly CSV downloads, retain `RAYLI` rows in
   zstd Parquet and `raw.rail_hourly`, and record source metadata and coverage in
   `raw.hourly_transport_months`.
2. Staging and station name mapping.
3. Comparison with daily data and month quality flags.
4. MCP tools and agent integration.

## Decisions

- Cover all months from 2020-01 through 2024-12. Bad months will be flagged,
  not dropped; stage 1 records measurements without assigning quality flags.
- Downloads are about 0.3–1.8 GB per month. Delete the raw CSV only after
  verification, a successful database transaction and Parquet replacement. Keep only rail rows in
  Parquet and DuckDB; preserve all 13 source fields as VARCHAR.
- Derive the month from the Turkish resource name. December 2024 has a URL
  containing `202512`; retain `month=2024-12`, record `url_month=2025-12`, and warn.
- Skip a previously successful or empty month when its resource ID and source
  modification timestamp match, unless `--force` is given. Replace each month's
  raw rows and manifest together in one transaction.
- Write and verify `.parquet.tmp`, then load the database from that temporary file.
  Replace the final Parquet only after `COMMIT`. Transaction failure rolls back raw
  rows and manifest, preserves the old Parquet byte for byte and retains the CSV.
  Stop on the first error and clean temporary files. If replacement fails after
  `COMMIT`, the database is already new and Parquet remains old: report `Error:`,
  exit 1 and retain the CSV; rerun the month with `--force` to repair this narrow window.
- Metadata size is advisory. The 2021-10 run reported metadata `size=41,507,859`
  bytes versus `1,189,119,249` downloaded bytes. Warn on a difference and record
  `metadata_bytes BIGINT` alongside actual downloaded `bytes`; add the column to
  existing manifests without changing old rows (their value remains NULL).
  Validate the 13-column header, every rail date within the requested month and
  every hour in `00`–`23`. Check downloaded bytes against `Content-Length` when
  present without `Content-Encoding`; skip this check for encoded responses.
  These checks do not establish that every day or observation is present.

## Known quality issues

Reported by Morks on 2026-11-15; stage 3 will verify coverage:

- November and December 2024 contain only a header.
- August–October 2024 are small; October 2024 covers only 18 days.
- October 2021 may be partial.

## Done when — stage 1

- `uv run python ingest/hourly_transport.py --month 2024-01` loads one month;
  repeated `--month` selects several, and `--all` selects all available months.
  `--db` overrides the database and `--force` reloads matching sources.
- Downloads stream in 1 MiB chunks, validate unencoded `Content-Length`, and retry network
  and 5xx errors at most three times with 2/4 second waits; 4xx errors stop.
- Headers match exactly. Only rail rows enter Parquet and DuckDB, counts match,
  and the manifest records bytes, row counts and distinct rail dates with bounds.
  Header-only months record `empty` without creating Parquet or adding raw rows.
- MockTransport tests cover success, Turkish text, skip/force, month isolation,
  empty months, the December URL discrepancy, retries, invalid inputs, retained
  artifacts, byte-preserving transaction rollback, post-commit replacement failure,
  advisory metadata size, short downloads, encoded responses, date/hour validation
  and legacy manifest migration. Ruff and the full pytest suite pass.
- A real download is deferred to Morks; this implementation task uses no network.
