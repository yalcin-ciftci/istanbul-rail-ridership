# M0 — 2025 verisini ham tabloya yükle

Yazan: **Morks/Codex**. İnceleyen ve onaylayan: **Yalçın**.

## Amaç
İBB CKAN API'sinden 2025 yılı raylı sistem istasyon verisini çekip DuckDB'de `raw.rail_station_daily` tablosuna yüklemek. İkinci kez çalıştırınca veri çoğalmamalı.

## Bilinenler (2026-11-15, API'den doğrudan okundu)
- API kökü: `https://data.ibb.gov.tr/api/3/action/`
- Paket: `package_show?id=rayli-sistemler-istasyon-bazli-yolcu-ve-yolculuk-sayilari` → `result.resources[]` (her kaynakta `id`, `name`, `last_modified`, `url`)
- 2025 kaynağı: `cce8e138-686a-4b8d-bac0-c2a0ab294a6e` — 135.783 satır
- Satır çekme: `datastore_search?resource_id=<id>&limit=<n>&offset=<k>` → `result.records[]`, `result.total`
- Kolonlar (hepsi metin): `transaction_year, transaction_month, transaction_day, line, station_name, station_number, town, longitude, latitude, passage_cnt, passanger_cnt` (+ API'nin eklediği `_id`)
- Alternatif: kaynağın `url` alanındaki CSV'yi tek seferde indirmek. Seçim ve gerekçesi incelemede Yalçın'a sunulur, README'ye bir cümleyle yazılır.

## Yapılacaklar
1. `ingest/` altında çekme betiği.
2. `data/ulasim.duckdb` dosyasında `raw` şeması ve `raw.rail_station_daily` tablosu.
3. Kolonlar **olduğu gibi metin** kalır. Temizleme M1'de dbt'de yapılır, burada yapılmaz.
4. Her satıra üç kolon ekle: `resource_id`, `source_last_modified` (CKAN'dan), `ingested_at` (çalışma zamanı).
5. Tekrar çalıştırmada çoğalma olmasın. Bir yol: aynı `resource_id` satırlarını silip yeniden yazmak, tek işlem (transaction) içinde.
6. Kısa günlük: kaç satır geldi, ne kadar sürdü.

## Bitti sayılması için
- `uv run python ingest/<betik>.py` hatasız biter.
- `select count(*) from raw.rail_station_daily where resource_id = 'cce8e138-686a-4b8d-bac0-c2a0ab294a6e'` → **135783** (API'nin `total` değeriyle aynı).
- Betiği ikinci kez çalıştırınca sayı değişmez.
- Ağ hatası olunca betik anlaşılır bir mesajla durur. Yarım veri yazmaz.

## Kapsam dışı (sonraki aşamalar)
- 2021–2024 yılları (M2), tip dönüşümü ve temizlik (M1), zamanlama, MCP (M3).

## Uygulama notları
- `httpx.get(url, params=..., timeout=...)`, `resp.raise_for_status()`
- DuckDB'ye toplu yazma: satırları önce liste/sözlük olarak topla, sonra bir DataFrame/Arrow nesnesi üzerinden `insert into ... select * from <nesne>`.
- Sayfa boyutu için API sınırını dene (ör. 32000); `total`'a ulaşana kadar `offset` artır.
